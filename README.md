# 3D Interactive Developer Portfolio

A modern, high-performance 3D web portfolio designed to present full-stack software engineering projects with an interactive visual identity. Built with smooth Framer Motion interactions, responsive 3D visual elements, and authentic production project dossiers.

---

## 🚀 Key Features

- **Interactive 3D Elements**: Hardware-accelerated canvas experiences and dynamic lighting powered by Three.js and Framer Motion.
- **Production Project Showcases**: Dedicated case study modals and multi-view screenshots highlighting architecture, data layers, and live interfaces.
- **Fluid Micro-Interactions**: Physics-based cursor tracking, smooth layout transitions, and high-contrast dark visual aesthetics.
- **Fully Responsive**: Optimized across desktop monitors, laptops, tablets, and mobile viewports with zero layout shifts.

---

## 🛠️ Tech Stack

- **Core Framework**: React 18, TypeScript, Vite
- **Styling & Design**: Tailwind CSS, Glassmorphism
- **3D & Animation**: Three.js, @react-three/fiber, Framer Motion
- **Icons & UI Utilities**: Lucide React, Canvas utilities

## ⚡ Quick Start

### Prerequisites
- Node.js (v18.x or higher)
- npm or yarn

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/khokharyasir749/3D-Portfolio-Web-.git
   cd 3D-Portfolio-Web-
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
